# Laboratory Work 1 - HTML CV
### **Topic**: Personal CV page using HTML

## Description:
Personal Curriculum Vitae done using plain HTML and hosted via Github Pages and basic styling.

## Technological Stack:
1. HTML.

## Sections:
1. Personal Information - contains information about Name, Surname, Age and Contact Information, as well as the Image.
2. Personal Description - contains a small personal reflection on the experience and current state of things.
3. Education - information about past and current institutions.
4. Projects - embeds information about several important projects that were done during past years, both University and Hackathon projects.
